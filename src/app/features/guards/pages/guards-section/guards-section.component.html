Guard Validation Flow

El guard valida autenticación y rol antes de cargar la ruta protegida. Cada paso del flujo se ejecuta secuencialmente.

1. Click Button Usuario intenta navegar a ruta protegida inicio
2. Router Angular Router intercepta navegación routing
3. RoleGuard Guard valida token y rol validando
4. Auth Service Consulta token en LocalStorage validando
5. Acción Final Acceso autorizado o redirect resultado
Flujo de autorización: Si token existe y rol coincide → acceso permitido. Si token no existe → redirige a /auth/login. Si rol no coincide → redirige a /unauthorized.
